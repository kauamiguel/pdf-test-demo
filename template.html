HTML e estrutura de páginas

HTML (HyperText Markup Language) é a linguagem de marcação usada para estruturar conteúdo na web. Cada elemento HTML descreve um tipo de conteúdo, como títulos, parágrafos, listas e links.

Principais elementos

  • <h1> a <h6> — títulos e subtítulos
  • <p> — parágrafos de texto
  • <ul> / <ol> — listas não ordenadas e ordenadas
  • <a> — links para outras páginas ou recursos

CSS e estilização

CSS (Cascading Style Sheets) controla a apresentação visual do HTML: cores, fontes, layout e responsividade.

Conceitos importantes

  1. Seletores — como escolher quais elementos estilizar
  2. Especificidade — ordem de prioridade das regras
  3. Box model — conteúdo, padding, border e margin

Para gerar PDFs no servidor, podemos usar bibliotecas como WeasyPrint (Python), que interpreta HTML e CSS e produz PDF de alta qualidade.
